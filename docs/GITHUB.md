# Репозиторий проекта

Приватный репозиторий: https://github.com/DestYchen/dispatcher112-trainer

Основная ветка — `main`, удалённый репозиторий — `origin`. Обычная отправка последующих изменений:

```powershell
git add <изменённые-файлы>
git commit -m "Описание изменения"
git push
```

Опубликованы исходники, тесты, техническое задание, документация, скрипты установки и учебные справочники/ресурсы. Пароли `.env`, сертификаты и закрытые ключи, профили браузера, текущая база, резервные копии, подписанные служебные команды, локальные модели, образы Docker и готовый многогигабайтный офлайн-комплект остаются на этом компьютере.

Исходная локальная история до публикации сохранена в ветке `local-before-github`. Она содержит служебные данные этой установки и не предназначена для отправки. На GitHub отправляется только `main`; не используйте `git push --all`.

Новая установка из репозитория выполняется по README.md: создаются свои `.env` и сертификаты, загружаются зависимости и локальная модель. Show.cmd предназначен для уже установленного проекта.

После публикации показ, монитор проекта и Docker Desktop остановлены по просьбе пользователя. Данные и файлы установки сохранены.
