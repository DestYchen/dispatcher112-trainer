# Показ АРМ-112 за 5–7 минут

Инструкция для установленного проекта на этом компьютере. Включите Docker Desktop и дважды нажмите **Show.cmd** в корне проекта. Скрипт дождётся сервисов, подготовит два упражнения и откроет отдельные окна Chrome или Edge для преподавателя и обучающегося. Подготовка не запускает таймеры.

То же действие из PowerShell в папке проекта:

```powershell
.venv\Scripts\python.exe scripts\present.py
```

В каждом окне нажмите **«Вход в учебную систему»**. Учебные логины — `demo.teacher` и `demo.student`, пароль обоих — `Showcase112!`. Они уже подставлены в форму. Если администратор изменил пароль, введите новый: запуск показа его не сбрасывает.

## 1. Действия диспетчера

1. Расположите окна рядом. В окне обучающегося должно появиться ожидание занятия. В окне преподавателя выберите фильтр **«Показать занятия → Запланировано»**, найдите **«01 · Пожар в частном доме — действия ДДС»** и нажмите **«Открыть пульт»**. На пульте проверьте участника и карточку.
2. Начните занятие у преподавателя. У обучающегося откройте карточку и в течение **30 секунд** установите **«Принята»**. Покажите адрес, описание, два таймера и изменение статуса в пульте преподавателя.
3. Пройдите **«Реагирование начато → Прибыли → Работы ведутся»**. Поясняйте решения во время показа; на обработку выделено **5 минут**.
4. Откройте телефон кнопкой **«Телефония · Alt+T»** или Alt+T, наберите **2201**, нажмите «Вызов». Руководитель отвечает «Слушаю вас». Отвечайте текстом или кнопкой **«🎤 Ответить голосом»** (распознанный текст проверьте и отправьте Enter). Скажите «Дубининская улица, дом 28» — руководитель переспросит улицу; уточните, затем «пострадавших нет, пожарные выехали». После «Я вас понял, информация принята» установите **«Работы завершены»**.
5. У преподавателя покажите события и результат. Завершите занятие, откройте отчёт (отдельный экран, назад — «← К списку занятий»), выберите формат и нажмите «Скачать отчёт». Оценка рассчитывается по совершённым действиям; просрочка или пропуск доклада отразятся в разборе. Страница «Прогресс и ИИ» показывает рейтинг Эло и фразы из ночного обучения.

## 2. Заполнение карточки

1. У преподавателя начните запланированное занятие **«02 · Приём обращения — заполнение карточки»**. Первое занятие к этому моменту должно быть завершено.
2. У обучающегося откройте обращение. Перенесите имя, телефон (АОН) и адрес по полям: Улица «Дубнинская улица», Дом «28». Справа нажмите «Пожары и задымления» → «жилой дом» → «частный дом» → «открытое пламя»: итоговый тип определится сам, службы появятся в оранжевой панели. «+» добавляет службу из справочника АРМ-112.
3. Покажите сохранение черновика, затем нажмите **«Сдать карточку»** и подтвердите. Откроется сравнение с эталоном и объяснение оценки.
4. У преподавателя откройте участника в пульте: видны заполненные поля и результат. Завершите занятие. Для следующего показа снова запустите **Show.cmd**.

## Повторный запуск и остановка

Запуск повторно использует запланированные и текущие занятия. Завершённые занятия, записи, оценки и аудит сохраняются; для следующего показа создаются новые упражнения. В списке занятий есть поиск и фильтр статуса. Обычные учебные записи и занятия не изменяются.

Закрытие окон браузера не останавливает сервер. Остановка с сохранением данных:

```powershell
.venv\Scripts\python.exe scripts\compose.py down
```

Если Chrome и Edge отсутствуют, откройте `https://localhost:5173/?showcase=teacher` и `https://localhost:5173/?showcase=student` в двух независимых профилях браузера. Две вкладки одного профиля используют общую сессию. При изменённом порте используйте адрес, напечатанный скриптом. Для ручного открытия настройте доверие локальному сертификату по [TLS.md](TLS.md).

Окна Show.cmd используют отдельные профили `.presentation/teacher` и `.presentation/student` и доверяют ключу сертификата этой установки. Настройки обычного браузера и системное хранилище сертификатов не меняются. Учётные записи предназначены для учебного показа; администратор может отключить их после демонстрации.
