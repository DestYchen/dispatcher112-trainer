# Реплики учебной телефонии

Восемь WAV, PCM 16 бит, 24 кГц, моно. Синтез выполнен заранее скриптом `scripts/build_voices.py` на CPU (PyTorch 2.9.0); в сервере и браузере синтеза нет. Русские ударения расставлены в сборочном скрипте. Текст реплик соответствует телефонному справочнику.

| Голос | Спикер Silero | Абонент |
| --- | --- | --- |
| male_calm | ru_dmitriy | Оперативный дежурный, 2201 |
| male_brisk | ru_igor | Главный инженер, 2214 |
| female_calm | ru_ekaterina | Служба 112, 112 |
| female_brisk | ru_zinaida | Начальник смены, 2210 |

Модель: Silero `v5_cis_base_nostress`, лицензия MIT — [официальное описание](https://github.com/snakers4/silero-models#v5-cis-base-models) и LICENSE-SILERO.txt. Это модель семейства CIS base, а не русская модель v5_ru с другой лицензией.

Прямой сервер моделей был недоступен по TLS в среде сборки. Использовано [зеркало модели](https://huggingface.co/adeshkin/silero-models-v5-cis-base-nostress). SHA-256: `0405777e332906f0644e08a680f7cfdc2137ea864090079c1fdd30a43c1b8761`; проверен хеш LFS. `manifest.json` содержит источник, версии, тексты и хеши каждого WAV. Модель в поставку приложения не входит; WAV уже включены и готовы для изолированного запуска.

Для пересборки: установить `scripts/requirements-voices.txt`, выполнить `make voices`. Можно передать `--model` с ранее скачанной моделью и `--source-url` для фиксации её происхождения.
