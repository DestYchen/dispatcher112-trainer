# Шрифты отчёта

PTSans-400.ttf и PTSans-700.ttf собраны из поставляемых локальных WOFF2-подмножеств PT Sans скриптом `scripts/build_pdf_fonts.py` через FontTools. В PDF нужен единый шрифт: раздельные подмножества с одинаковым именем приводили к неправильной отрисовке цифр при корректном извлечении текста.

Исходные файлы и лицензия: `frontend/public/fonts/`. Эти TTF уже готовы и не требуют загрузки при запуске системы. Для пересборки достаточно установленного backend-окружения: `python scripts/build_pdf_fonts.py`.
