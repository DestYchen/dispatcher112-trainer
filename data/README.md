# Исходные данные

`classifier.xlsx` — реальный классификатор происшествий заказчика (ЕКП v046_24), сконвертированный `scripts/convert_real_classifier.py` (23 группы, 1131 тип, 230 служб). `services_directory.txt` — справочник служб окна «Добавьте службы», перенесённый со скриншотов заказчика. `classifier-synthetic.xlsx` — прежний учебный классификатор, фикстура тестов.

`tickets/tickets.json` — 96 ситуаций из 32 билетов заказчика «Билеты-задачи по С 112», перенесены со сканов и сверены вручную.

`dialogue/boss_graph.json` — граф разговора с руководителем; `dialogue/proposals.json` появляется после ночного обучения.

`streets.csv` — учебный справочник из 50 улиц, включая Дубнинскую и Дубининскую. Полный справочник загружается тем же импортёром.

`stt/` — офлайн-модель распознавания речи (не в репозитории, скачивается `scripts/prepare_stt.py`).
