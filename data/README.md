# Исходные данные

В исходном репозитории отсутствовали XLSX, справочник улиц и билеты. Поставляемый classifier.xlsx — авторский учебный набор, а не нормативный классификатор АРМ-112. Он содержит 24 предметные группы, 1200 различных сочетаний объектов и характера происшествия, 58 служб с маршрутизацией и правила расширения по модификаторам. Все записи используются приложением.

Воспроизводимый источник: scripts/build_training_data.py. Листы XLSX: services, incident_groups, incident_types, modifier_services; заголовки полей канонические, ссылки по code. Лист README явно описывает происхождение. streets.csv содержит ограниченный справочник из 50 московских улиц, включая Дубнинскую и Дубининскую. Полный городской справочник можно загрузить тем же импортёром.

Исходные билеты заказчика отсутствуют. Приёмка OCR на реальных билетах требует соответствующего входного корпуса; искусственные билеты нельзя выдавать за него.
