# Учебные билеты

Исходные PDF заказчика не предоставлены. Положите их в этот каталог и выполните:

```
docker compose run --rm backend python -m app.seeds.import_tickets /data/tickets/имя.pdf
```

OCR выполняется локально: OCRmyPDF → Tesseract (`rus`) → `pdftotext -layout`.
Импорт ожидает таблицу «№ / Ситуация / Адрес». Повторный импорт одного PDF не дублирует билеты.
ФИО и телефоны заменяются до записи описания в БД. Улицы вне справочника и строки без распознанного типа не импортируются; число отклонённых строк выводится в отчёте команды.

Сопоставление типа по словам предварительное: каждый билет остаётся `PENDING_REVIEW`, его обязан проверить преподаватель. Пример `sample-ocr.pdf`, если создан тестовым скриптом, — авторская синтетическая фикстура, а не исходный материал заказчика.
