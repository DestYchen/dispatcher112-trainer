# Локальные шрифты

PT Sans 400/700 и PT Mono 400. Источник файлов: пакеты @fontsource/pt-sans и @fontsource/pt-mono, версия 5.2.7, registry.npmjs.org; SHA-512 архивов проверен по dist.integrity при получении.

Это локальные статические ресурсы. Браузер не обращается к Google Fonts, Fontsource, npm или CDN. Лицензии OFL приложены в pt-sans-LICENSE.txt и pt-mono-LICENSE.txt. fonts.css задаёт unicode-range для кириллицы, латиницы и расширений.
